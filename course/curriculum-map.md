# 模态逻辑六讲：课程地图

> 这不是章节目录，而是回答四个问题：**给谁学、先会什么、六讲怎么依赖、学完能做什么。**

## 1. 对象与不面向谁

**适合**

- 已学过命题逻辑，想系统入门模态逻辑的本科生/研究生；
- 哲学、逻辑学、计算机科学、语言学方向，需要处理“必然/可能/知道/应当/时间”的读者；
- 想动手写 Kripke 模型、反模型、表列或 Lean 形式化的自学者。

**不完全适合**

- 完全没接触过命题逻辑的读者：请先补真值表、重言式、MP；
- 只想学“模态逻辑哲学史”的读者：本课程以技术入门为主，历史与争论只做入口；
- 想直接做高阶模态逻辑研究（可证性逻辑、拓扑语义、高阶完全性）的读者：本课程只到标准系统与完全性骨架。

## 2. 先修与诊断

**必须会**

1. 命题联结词 `¬ ∧ ∨ → ↔` 的真值表；
2. 重言式、代入、分离规则（MP）；
3. 集合、二元关系、函数的基本记号；
4. 能用自然语言解释“充分条件/必要条件”。

**自测（能答出 3 题再开始）**

- `p → (q → p)` 为什么是重言式？
- “所有 A 都是 B”与“如果 A 则 B”在真值表上有什么关系？
- 一个二元关系“自反”是什么意思？举一个自反和一个非自反的例子。
- 如果 `R = {(0,1)}`，那么从 0 出发能到达哪些点？

**不要求**

- 一阶逻辑的完备性定理；
- 代数/范畴论背景；
- 编程经验（Lab 有 Python 入门注释，但不会编程也能读讲义）。

## 3. 四个核心问题

整个课程围绕四个问题反复推进：

1. **表达**：怎样把“必然/可能/知道/应当/将来”写进形式语言，而不把不同含义混成一个 `□`？
2. **语义**：一个模态公式在什么情况下为真？为什么需要“可能世界 + 可及关系”？
3. **证明**：哪些公式在哪个系统中可证？语义有效与语法可证如何对应？
4. **应用**：面对知识、时间、义务等场景，怎样选系统、建模型、检验结论，并说明模型的边界？

## 4. 六讲依赖图

```text
[1] 命题逻辑 + 模态语言
        │  语法、辖域、翻译
        ▼
[2] Kripke 语义 + 反模型
        │  框架/模型/满足/有效性
        ├──────────────┐
        ▼              ▼
[3] 公理系统       [5] 表列法
    K/T/S4/S5         证明搜索/反模型
        │              │
        ▼              │
[4] 框架对应 + 完全性  │
        │              │
        └──────┬───────┘
               ▼
        [6] 应用：认知/时间/道义
```

读法：

- 1 是语言入口；没有 1，2 的公式读不懂。
- 2 是语义入口；没有 2，3 的“可靠性”没有内容，5 的“反模型”没有目标。
- 3 和 4 是证明论/元理论主线；3 先给系统，4 再解释系统为什么匹配框架。
- 5 是算法主线，可以独立于 4 学，但需要 2 的语义直觉。
- 6 是应用出口，需要 2 的模型、3 的系统选择、5 的反模型检验。

## 6. 范围边界

**本课程覆盖**

- 命题模态逻辑的正常系统 K/T/K4/S4/S5/D/B/KD45；
- Kripke 语义、框架对应、反模型、表列法；
- 可靠性与完全性的证明结构（不要求完整形式化）；
- 认知、时间、道义三个应用方向的基本建模。

**本课程不覆盖**

- 一阶模态逻辑、高阶模态逻辑；
- 可证性逻辑 GL 的完整理论；
- 拓扑/邻域/关系语义的深入比较；
- 代数逻辑、范畴论视角；
- 自动定理证明器的工程实现；
- 模态逻辑的完整哲学史。

遇到这些内容，课程只给“入口”和“进一步阅读”，不假装讲完。

## 7. 顺序理由

1. **先语言后语义**：不先定义公式，就无法定义满足关系。
2. **先语义后证明**：反模型能让学生“看见”一个公式为什么不成立，再学公理系统时知道证明在排除什么。
3. **先 K 后扩张**：K 是最小正常系统；T/4/5/B/D 都是在 K 上加条件，便于看清“加一条公理改变了什么”。
4. **先对应后完全性**：对应是具体的、可画图的；完全性是抽象的，需要前面的框架直觉做支撑。
5. **表列法放在对应之后**：表列法同时使用语义（反模型）和证明（闭枝）直觉；此时学生已具备两者。
6. **应用放在最后**：应用需要模型、系统、反模型三种能力；太早讲会变成术语堆砌。

## 8. 三条学习路径

### 核心版（6 × 1 小时）

- 每讲只读“导入 + 定义 + 一个完整例题 + 常见错误 + 要点”；
- 跳过第四讲的完全性细节、第五讲的终止性证明；
- 做每讲 2 道基础题；
- 目标：能读模态公式、能求值、能构造简单反模型、能选系统。

### 完整版（6 × 2 小时）

- 按六讲顺序，补第四讲对应证明、第五讲表列练习；
- 做每讲 4–6 题，至少 1 道迁移题；
- 加一次精读页/实验室动手；
- 目标：能写 Hilbert 证明、能手写表列、能复述完全性结构。

### 编程/项目版

- 完整版 + Lab 1–6；
- 用 `modal_lab.py` 验证反模型、框架性质、Hilbert 证明；
- 期末项目：选一个场景，建模型、写公式、给证明或反模型，并说明边界；
- 目标：能把“模态逻辑”变成可运行、可检验的模型。

## 10. 学完后的出口能力

达到“完整版”后，学生应能：

1. 看到一个自然语言句子，判断是否需要模态，写出公式并指出辖域歧义；
2. 给定模型，逐子公式求值，并用反模型证明一个公式不有效；
3. 写出 K/T 中的简单 Hilbert 证明，区分 K/T/S4/S5/D/B 的定理集；
4. 解释标准公理与框架条件的对应，复述典范模型完全性证明的结构；
5. 手写 K 的表列，判断闭枝/开放枝，从开放枝提取反模型；
6. 为知识、时间、义务场景选择系统，建最小模型，并说明模型的理想化边界。
