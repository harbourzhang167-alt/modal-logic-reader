# 第三讲 公理系统 K、T、S4、S5

**本讲导入。** 第 2 讲用模型判断“这个公式在这个世界里真不真”；但有时我们想要一个更硬的结论：**在某个系统中，这个公式能不能从公理推出来**。语义有效性是对所有模型/世界的全局断言，证明则是有限行的证书。Hilbert 系统就是这种证书的最小格式：几条公理模式，加两条规则，就能把“为什么可证”写成可检查的序列。本讲先学写证明，再理解 K/T/S4/S5 这些系统为什么这样扩展；完全性留到第 4 讲。

## 学习目标

学完本讲，你应当能：

- 写出 K 的公理模式、MP、NEC，并解释“公理模式”与“公理实例”的区别；
- 在 K 中写出 3–5 行的简单证明，并说明每一步用了哪条公理/规则；
- 在 T 中证明 `p → ◇p`，并解释为什么它在 K 中不成立；
- 画出 K/T/S4/S5/D/B 的包含关系，并用框架条件解释方向；
- 识别“对假设用 NEC”“K 方向写反”“在 K 中用 T”三类错误证明。

**先修回顾。** 本讲需要：第 1 讲的公式语法；第 2 讲的满足/有效性；命题重言式与 MP；对“证明序列”的递归理解。开始前自测：`p → (q → p)` 是重言式吗？如果 `A` 是定理，NEC 能得到什么？如果 `A` 只是假设，NEC 还能用吗？第三问是本讲最重要的边界。

**本讲在课程中的位置。** 第 3 讲给“语法证明”，第 4 讲给“语义对应”，两者合起来才是可靠性与完全性。表列法（第 5 讲）是另一种证明搜索方式；Hilbert 证明适合验证和元理论，不适合手工搜索。实验室的证明检查器可以逐行验证本讲的证明。

## 3.1 为什么需要公理系统

语义告诉我们“什么在框架上有效”，证明系统告诉我们“什么可以从公理和规则推出”。一个理想的系统要满足：

- **可靠性（soundness）**：能证明的公式都有效。
- **完全性（completeness）**：有效的公式都能证明。

K 是最小的正常模态逻辑。所谓“正常”，是指它包含命题逻辑、K 公理，并对 MP 和必然化封闭。

## 3.2 Hilbert 系统 K

**公理模式**：

1. 所有命题重言式的代入实例。
2. `K`：`□(A → B) → (□A → □B)`。

**推理规则**：

- **MP**：从 `A` 和 `A → B` 推出 `B`。
- **必然化（NEC）**：从 `A` 推出 `□A`。

一个**证明**是一个有限公式序列，其中每一步要么是公理实例，要么由前面的行经 MP 或 NEC 得到。最后一行就是被证明的定理。

**定义拆解。**

1. **公理模式 vs 公理实例**：`□(A → B) → (□A → □B)` 是模式，`A`、`B` 是元变量；把 `A` 取 `p`、`B` 取 `q` 得到的是实例。写证明时用的是实例，但引用时可以写“K”。
2. **证明序列**：有限行；每一行必须有依据（taut、K、MP、NEC）。不允许写“显然”跳过一行，除非那一行是前面某行的重言式代入实例，并能说明。
3. **定理 vs 假设**：定理是序列最后一行，且序列中每一行都合法；假设是“如果 A 成立，那么……”里的 A。NEC 只对**定理**使用，不对假设使用。
4. **NEC 的方向**：`A ⊢ □A`；不是 `□A ⊢ A`。前者是必然化，后者是 T 公理，只在 T 及更强系统中成立。
5. **K 的形状**：`□(A→B) → (□A→□B)` 说“必然性分配到蕴涵上”。它的逆 `(□A→□B) → □(A→B)` 不是 K 的定理；分配不是等价。

**为什么要有 K？** 它是最小的“正常”分配条件：如果每个可及世界都满足 `A→B`，并且每个可及世界都满足 `A`，那么每个可及世界都满足 `B`。这条直觉在 Kripke 语义下自动成立，所以 K 对所有框架有效。其他公理（T/4/5/B/D）则是对可及关系加条件；第 4 讲会把这个对应写清楚。

注意：NEC 只能对**已经证明的定理**使用，不能对任意假设使用。否则会从 `p` 推出 `□p`，而 `p → □p` 并不是 K 的定理。

## 3.3 三个 K 中的证明

### 证明 1：`□(p → p)`

```text
1. p → p                       taut
2. □(p → p)                    NEC 1
```

### 证明 2：`□p → □(q → p)`

```text
1. p → (q → p)                 taut
2. □(p → (q → p))              NEC 1
3. □(p → (q → p)) → (□p → □(q → p))   K
4. □p → □(q → p)               MP 2,3
```

### 证明 3：`□(p ∧ q) → □p`

```text
1. (p ∧ q) → p                 taut
2. □((p ∧ q) → p)              NEC 1
3. □((p ∧ q) → p) → (□(p ∧ q) → □p)   K
4. □(p ∧ q) → □p               MP 2,3
```

把 `p` 换成 `q`，同理可证 `□(p ∧ q) → □q`；再用命题逻辑组合，就能得到：

```text
□(p ∧ q) → (□p ∧ □q)
```

完整证明需要 11 行，见 `code/lab05_proofs.py` 的参考答案。

**证明策略。** 以证明 2 为例，不要从目标倒着猜，而按四步走：

1. **找命题骨架**：目标 `□p → □(q→p)` 的前件是 `□p`，后件是 `□(q→p)`；要把后件变成“必然化”的形式，先需要命题重言式 `p → (q→p)`。
2. **必然化**：对重言式用 NEC，得到 `□(p→(q→p))`。
3. **套 K**：把 K 实例化为 `□(p→(q→p)) → (□p→□(q→p))`。
4. **MP**：用第 2 行和第 3 行推出目标。

| 行 | 公式 | 依据 | 在策略中的角色 |
|---|---|---|---|
| 1 | `p → (q→p)` | taut | 提供命题骨架 |
| 2 | `□(p→(q→p))` | NEC 1 | 把骨架变成必然性 |
| 3 | `□(p→(q→p)) → (□p→□(q→p))` | K | 分配必然性 |
| 4 | `□p → □(q→p)` | MP 2,3 | 得到目标 |

**错误证明诊断。**

- **对假设用 NEC**：

  ```text
  1. p                 假设
  2. □p                NEC 1   ← 非法
  ```

  如果这合法，就能从任意假设 `p` 推出 `□p`，从而证明 `p→□p`；但第 2 讲已给反模型，`p→□p` 不是 K 的定理。错误根源是把“假设真”当成了“定理”。
- **把 K 的方向写反**：K 是 `□(A→B) → (□A→□B)`，不是 `(□A→□B) → □(A→B)`。后者会把“必然 A 蕴涵必然 B”误当成“必然(A→B)”，在语义上要求过强。
- **在 K 中直接用 T**：`□p→p` 需要自反性；K 的框架允许空可及关系，所以它不是 K 的定理。写证明时每引用一条公理，都要问：这条公理属于当前系统吗？

## 3.4 扩展公理与系统

在 K 上增加以下公理模式，得到不同的系统：

- `T`：`□A → A`（必然蕴涵实际）
- `4`：`□A → □□A`（必然的必然）
- `5`：`◇A → □◇A`（可能的必然化）
- `B`：`A → □◇A`（实际蕴涵必然可能）
- `D`：`□A → ◇A`（必然蕴涵可能；排除义务冲突）

常见系统：

```text
T   = K + T
K4  = K + 4
S4  = K + T + 4
S5  = K + T + 4 + 5      （也等价于 K + T + 5）
D   = K + D
B   = K + T + B
K5  = K + 5
KD45 = K + D + 4 + 5
```

系统之间的包含关系（按定理集）：

```text
K ⊂ T ⊂ S4 ⊂ S5
K ⊂ K4 ⊂ S4
K ⊂ D ⊂ T
T ⊂ B ⊂ S5
S4 ⊂ S5
```

注意：

- `D` 比 `T` 弱：T 可以证明 D，但 D 不能证明 T。
- `B` 与 `S4` 互不包含；`S5` 同时包含两者。
- `K5` 比 `S5` 弱，但比 K 强。

这些包含关系可以用语义对应来记：T 对应自反，4 对应传递，5 对应欧几里得，B 对应对称，D 对应串行。自反框架一定是串行的，所以 T 蕴涵 D。

**为什么包含关系是这个方向？** 加公理不是“让系统更弱”，而是**缩小允许的框架类**：框架条件越多，能用的框架越少，但能证明的公式越多。于是：

- `K ⊂ T`：T 只允许自反框架，自反框架类 ⊂ 所有框架类，所以 T 的定理集更大。
- `D ⊂ T`：自反 ⇒ 串行，所以自反框架类 ⊂ 串行框架类；T 比 D 强。
- `S4 ⊂ S5`：等价关系同时自反、传递、欧几里得，S5 的框架类更窄，定理更多。
- `B` 与 `S4` 不可比：一个加对称，一个加传递；两个条件互不包含，所以定理集互不包含。
- `K5` 比 `S5` 弱：K5 只有欧几里得，没有自反和传递；S5 三条都有。

这个“框架类越窄、定理越多”的方向，是第 4 讲对应理论的语义版。不要把 `⊂` 读成“公式更少”；它读作“系统更强/定理集更大”。

## 3.5 T 中的证明：`p → ◇p`

约定 `◇A` 是 `¬□¬A` 的缩写。

```text
1. □¬p → ¬p                    T（A 取 ¬p）
2. (□¬p → ¬p) → (p → ¬□¬p)     taut
3. p → ¬□¬p                    MP 1,2
```

最后一行就是 `p → ◇p`。这个证明说明：在 T 中，实际真蕴涵可能真；在 K 中则不然（第二讲的反模型：空可及关系）。

**对照：同一个公式在不同系统中的命运。** 用第 2 讲的反模型方法，可以快速判断一个公式“至少需要多强”的系统：

| 公式 | K | T | S4 | S5 | 失败原因 |
|---|---|---|---|---|---|
| `□p → p` | 否 | 是 | 是 | 是 | K 允许空可及关系 |
| `p → □p` | 否 | 否 | 否 | 否 | 实际真不蕴涵必然真 |
| `□p → □□p` | 否 | 否 | 是 | 是 | 需要传递性 |
| `◇p → □◇p` | 否 | 否 | 否 | 是 | 需要欧几里得（S5） |
| `p → □◇p` | 否 | 否 | 否 | 是 | 需要对称（B 也有，但 B 不在表内） |

这张表不是让你背“哪个系统有哪些定理”，而是让你看到：**公理的选择等价于对可及关系加条件**。第 4 讲会把这张表变成对应证明。

**常见错误诊断。**

1. **“K 是公理，所以 K 能证明一切重言式。”** K 只包含命题重言式的代入实例，不包含 T/4/5/B/D。`□p→p` 不是重言式，也不在 K 中。
2. **“系统越强，公理越少。”** 反了：系统越强，允许的框架越窄，定理越多；公理是增加的。
3. **“NEC 可以从任何真公式推出必然。”** NEC 只对**定理**使用；对假设用 NEC 会推出 `p→□p`，而这是无效的。
4. **“S5 就是所有世界互相可及。”** 这是第 5 讲会修正的表述：S5 框架是等价关系，可能分成多个互不相交的等价类；每个类内互相可及，不同类之间不可及。

**应用与边界。** Hilbert 系统适合做**证书**：给定一个证明，逐行检查它是否合法；也适合证明关于系统的元定理（可靠性、完全性、独立性）。它不适合“从零搜索证明”——那需要表列法或自动定理证明。正常模态逻辑是本章的对象；非正常系统、模态逻辑的代数语义不在本课程范围内。

**迁移检验。** 试着在 K 中证明 `□(p→q) → (◇p→◇q)`。提示：先把 `p→q` 换成它的逆否命题 `¬q→¬p`，用 NEC 和 K 得到 `□¬q→□¬p`，再用命题逻辑的逆否得到 `◇p→◇q`。如果你能写出这四步，说明你已经掌握“重言式 + NEC + K + MP”的组合。

## 3.6 可靠性与完全性

**可靠性**：若 `⊢_K A`，则 `A` 在所有框架上有效；若 `⊢_T A`，则 `A` 在所有自反框架上有效；S4、S5、D、B 类似。

**完全性**：反过来也成立。K 对所有框架完全，T 对自反框架完全，S4 对自反传递框架完全，S5 对等价关系框架完全，D 对串行框架完全，B 对自反对称框架完全。

完全性的标准证明用**典范模型**：

1. 把“极大一致集”当作世界；
2. 定义 `w R v` 当且仅当 `{A | □A ∈ w} ⊆ v`；
3. 证明真值引理：`A ∈ w` 当且仅当 `(M, w ⊨ A)`；
4. 由典范模型的存在得到“一致则可满足”，再取逆否得到完全性。

第四讲会展开这个思路；本课程不要求写出完整的形式证明，但要求能复述证明结构。

## 3.7 本讲要点

- K = 命题重言式 + K 公理 + MP + NEC；NEC 只对定理使用。
- 公理模式是“模板”，证明里用的是实例；证明是有限、逐行有依据的序列。
- T/4/5/B/D 分别对应自反/传递/欧几里得/对称/串行；加公理 = 缩小框架类 = 扩大定理集。
- K ⊂ T ⊂ S4 ⊂ S5；D ⊂ T；B 与 S4 不可比。
- 可靠性 + 完全性 = 语法与语义匹配；证明细节在第 4 讲。
