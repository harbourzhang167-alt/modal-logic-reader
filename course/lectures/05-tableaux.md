# 第五讲 表列法与证明搜索

**本讲导入。** 第 3 讲的 Hilbert 证明适合“检查一个已经写好的证明”，但不适合“从零找到证明”：你很难猜出该用哪条重言式、哪条 K 实例。表列法换一个方向：假设目标公式为假，然后像解谜一样把它的结构拆开；如果所有分支都矛盾，目标有效；如果有一条分支始终开放，这条分支本身就是反模型。它把“证明”和“找反例”变成同一个搜索过程。

## 学习目标

学完本讲，你应当能：

- 写出带前缀的公式、初始节点、闭枝条件，并解释每个记号的含义；
- 对 K 的 α/β 规则和四条模态规则，判断下一步该用哪条；
- 手写 `□(p→q) → (□p→□q)` 的表列，并说明两个分支为什么都闭；
- 从开放枝读出一个反模型，并验证它确实使目标公式为假；
- 说明 `F(□φ)` 为什么必须创建新世界，以及阻塞如何保证终止；
- 正确表述 S5 的等价类语义，不把“类内互相可及”说成“所有世界互相可及”。

**先修回顾。** 本讲需要：第 2 讲的满足关系（特别是 `□`/`◇` 的全称/存在读法）；树与递归；反证法；第 4 讲的框架性质。开始前自测：`F(□φ)` 表示什么？它需要“存在一个可及世界使 φ 假”，还是“所有可及世界使 φ 假”？答案：存在。这个存在性正是“创建新世界”的来源。

**本讲在课程中的位置。** 表列法是第 2 讲语义和第 3 讲证明的交汇：闭枝对应“没有反模型”，开放枝对应“有反模型”。第 4 讲的框架规则在这里变成搜索规则；实验室的 trace 会把逐子公式求值展开，可以和手写表列对照看。

## 5.1 从证明到反驳

Hilbert 系统适合“验证一个给定证明”，但不适合“自动找证明”。表列法反过来做：

> 要证明 `φ` 有效，先假设 `φ` 为假，然后系统地展开所有可能性。如果所有分支都矛盾，则 `φ` 有效；如果某个分支保持开放，则它给出一个反模型。

**为什么这算证明？** 因为展开规则是“保满足性”的：如果原公式有一个反模型，那么每一条规则应用后，至少有一个分支仍然能被这个反模型满足；反过来，任何开放枝都能读出一个反模型。于是：

- 所有分支闭 → 假设“存在反模型”导致矛盾 → 原公式有效；
- 某枝开放 → 该枝直接给出反模型 → 原公式无效。

这不是“随便拆一拆”，而是对“反模型存在性”做系统搜索。每一步都要问：这条规则是否保持了“存在一个模型满足该枝”的可能性？

因此，表列法同时是：

- 一个证明搜索过程；
- 一个反模型构造过程。

## 5.2 带前缀的公式

表列法的节点是带世界前缀的公式：

```text
T φ @ w     表示“φ 在 w 为真”
F φ @ w     表示“φ 在 w 为假”
```

初始节点：`F φ @ w0`（要证 `φ` 有效，就假设它在某个世界为假）。

分支用缩进或树形表示。闭枝条件是同一世界上同时出现 `T ψ` 和 `F ψ`。

**记号拆解。** 把 `T ψ @ w` 读成“在当前尝试构造的反模型里，`ψ` 在世界 `w` 为真”；`F` 则读成“为假”。它不是对象语言里的公式，而是元语言里的**约束**。前缀 `w` 是搜索过程中给世界起的名字，不是固定的自然数。

- **初始节点**只有一个：`F φ @ w0`。这表示“假设存在一个世界让 `φ` 假”。
- **同枝**上的节点共享同一组世界和可及关系；**不同枝**是搜索的不同情况，不能把一枝的节点搬到另一枝。
- **闭枝**：同一世界同时要求 `ψ` 真和假。这说明这条搜索路径不可能有模型。
- **开放枝**：所有规则都用尽仍没有 `T ψ`/`F ψ` 冲突。它给出一个候选反模型；但还要检查可及关系和赋值是否自洽（第 5.7 节会做）。

**一个常见误解。** `F φ @ w` 不是“φ 在世界 w 为假”这个语义事实，而是“我们正在尝试让 φ 在 w 为假”。前者是模型里的真值，后者是搜索中的目标。把两者混在一起，就会误以为 `F` 节点本身已经构造好了反模型。

## 5.3 命题规则

**非分支规则（α）**：

- `T(φ ∧ ψ)`：加 `T φ`、`T ψ`。
- `F(φ ∨ ψ)`：加 `F φ`、`F ψ`。
- `F(φ → ψ)`：加 `T φ`、`F ψ`。
- `T(¬φ)`：加 `F φ`。
- `F(¬φ)`：加 `T φ`。
- `T(φ ↔ ψ)`、`F(φ ↔ ψ)`：展开成两个方向的蕴涵，再按规则处理。

**分支规则（β）**：

- `T(φ ∨ ψ)`：分支为 `T φ` 或 `T ψ`。
- `F(φ ∧ ψ)`：分支为 `F φ` 或 `F ψ`。
- `T(φ → ψ)`：分支为 `F φ` 或 `T ψ`。

**为什么 α 不分支、β 要分支？** α 规则对应“一个约束同时要求两件事”，例如 `T(φ∧ψ)` 要求两者都真，所以在同一枝上直接加两个节点；β 规则对应“一个约束给出两种可能”，例如 `T(φ∨ψ)` 只要求至少一个真，所以分成两枝分别尝试。分支不是“任意选择”，而是穷尽所有可能；所有分支都闭才算证明完成。

**规则的方向。** 注意 `F(φ→ψ)` 加的是 `T φ` 和 `F ψ`：要让蕴涵假，必须前件真、后件假。反过来，`T(φ→ψ)` 分成 `F φ` 或 `T ψ`：蕴涵真只有这两种可能。写反方向是表列法最常见的错误之一。

## 5.4 模态规则

**T(□φ) @ w**：

- 对每个已经存在的 `v`，若 `wRv`，加 `T φ @ v`。
- 若 `w` 还没有可及世界，什么也不做。因为 `□φ` 在空可及关系下空真。

**F(□φ) @ w**：

- 创建一个**新**世界 `v`，加 `wRv` 和 `F φ @ v`。
- “新”很重要：它不能是已经存在的世界，否则会错误地限制反模型的大小。

**T(◇φ) @ w**：

- `◇φ` 是 `¬□¬φ`，所以先转成 `F(□¬φ)`，再创建新世界 `v`，加 `wRv` 和 `T φ @ v`。

**F(◇φ) @ w**：

- `◇φ` 是 `¬□¬φ`，所以先转成 `T(□¬φ)`，再对所有 `wRv` 的 `v` 加 `F φ @ v`。

**四条规则背后的语义。** 把 `□` 读成“所有可及世界”，`◇` 读成“存在可及世界”，规则就不是背出来的：

- `T(□φ)` 说“所有 `w` 的可及世界都满足 `φ`”，所以对每个已经存在的 `wRv`，把 `T φ` 加到 `v`。这里用“已经存在”，是因为它不主动创造新世界。
- `F(□φ)` 说“并非所有可及世界都满足 `φ`”，等价于“存在一个可及世界满足 `¬φ`”。要构造这个见证，就创建一个**新**世界 `v`，加 `wRv` 和 `F φ @ v`。如果复用旧世界，就可能把本来可以更大的反模型强行做小，导致误判为闭枝。
- `T(◇φ)` 是“存在可及世界满足 `φ`”，同样需要新世界。
- `F(◇φ)` 是“所有可及世界都满足 `¬φ`”，所以只向已有可及世界传播，不创建新世界。

**“新”到底新在哪？** 新世界必须没有出现在当前枝的任何前缀里，也不能与已有世界合并。它类似一阶逻辑证明里的“任取一个未用过的常项”：如果你用了一个已经被约束过的名字，就相当于额外假设了两个世界相同，可能排除掉真正的反模型。反过来，如果 `w` 没有任何可及世界，`T(□φ)` 什么也不加，因为全称条件在空集上为空真；这正是 `□p → p` 在 K 中失败的原因。

## 5.5 例子：K 公理

要证 `□(p → q) → (□p → □q)` 有效，初始：

```text
T □(p → q) @ 0
F (□p → □q) @ 0
```

展开：

```text
T □p @ 0
F □q @ 0
0R1, F q @ 1          （F□ 创建新世界）
T p @ 1               （T□p 传播到 1）
T (p → q) @ 1         （T□(p→q) 传播到 1）
├─ F p @ 1            （T→ 分支 1）
│  └─ 闭：T p 与 F p
└─ T q @ 1            （T→ 分支 2）
   └─ 闭：T q 与 F q
```

两个分支都闭，所以原公式有效。

**把树读一遍。** 第一步不是急着分支，而是先把能线性展开的 α 规则用掉：由 `F(□p→□q)@0` 得到 `T □p@0` 与 `F □q@0`；由 `F □q@0` 创建新世界 `1` 并得到 `0R1`、`F q@1`；再把两个 `T □` 传播到 `1`，得到 `T p@1` 与 `T(p→q)@1`。最后 `T(p→q)@1` 是 β，才分成 `F p@1` 和 `T q@1` 两枝。先做 α 后做 β 通常能让树更小；这不是逻辑上的强制，而是搜索策略。无论先做哪条，只要所有分支都闭，结论一样。

**为什么两个分支都闭？** 左枝有 `T p@1`（来自 `T□p`）和 `F p@1`（来自 `T(p→q)` 的 β 左支），右枝有 `T q@1`（来自 `T(p→q)` 的 β 右支）和 `F q@1`（来自 `F□q`）。闭枝条件只要求同一世界上有同一公式的 `T` 和 `F`，不要求它们相邻。

## 5.6 例子：`□p → p` 在 K 中

```text
T □p @ 0
F p @ 0
```

`T □p` 要求传播到 0 的可及世界；但 0 还没有可及世界，所以不传播。没有其他规则可用，分支开放。

从开放枝读反模型：

```text
W = {0},  R = ∅,  p 在 0 为假
```

`□p` 在 0 空真，`p` 在 0 假，所以 `□p → p` 失败。这正是 T 公理在 K 中不成立的原因。

如果我们在 T 中做表列，加入自反规则 `0R0`，就会得到 `T p @ 0`，与 `F p @ 0` 闭枝。所以 `□p → p` 在 T 中有效。

## 5.7 例子：`p → □p`

```text
T p @ 0
F □p @ 0
0R1, F p @ 1
```

没有规则可以继续；分支开放。反模型：

```text
W = {0,1},  R = {(0,1)},  p 在 0 真、在 1 假
```

这说明“实际真”不蕴涵“必然真”。

## 5.8 框架规则

- **T**：对每个世界 `w`，加 `wRw`（自反）。
- **4**：若 `wRv` 且 `vRu`，加 `wRu`（传递）。
- **5**：若 `wRv` 且 `wRu`，加 `vRu`（欧几里得）。
- **B**：若 `wRv`，加 `vRw`（对称）。
- **D**：若 `w` 没有可及世界，创建一个新世界 `v` 并加 `wRv`（串行）。

**S5 的关系是等价关系。** 等价关系把世界分成互不相交的**等价类**：同一类内的世界互相可及，不同类之间不可及。因此，在 S5 中：

- `□φ` 在 `w` 为真，当且仅当 `φ` 在 `w` 所在的整个等价类中为真；
- `◇φ` 在 `w` 为真，当且仅当 `φ` 在 `w` 的等价类中至少一个世界为真。

注意：**不是“所有世界互相可及”**。S5 的框架可以有两个互不相交的等价类；类内的 `□`/`◇` 只在本类内量化。说“所有世界互相可及”是“单类 S5 框架”的特例，不是 S5 的定义。这个区别在反模型和表列的 S5 规则里都会出现：S5 规则允许你在 `w` 的等价类内合并世界，但不能把不同类的世界强行连起来。

**S5 仍然可能需要多个世界。** 例如 `◇p ∧ ◇¬p` 在同一个等价类里需要至少两个世界：一个满足 `p`，一个满足 `¬p`。如果只有一个世界，`p` 和 `¬p` 不能同时成立。所以“S5 可以看成一个类”不等于“S5 只有一个世界”。

## 5.9 例子：`◇p → □◇p` 在 S4 与 S5

在 S4（自反 + 传递）中，这个公式**不**有效。反模型：

```text
W = {0,1},  R = {(0,0), (0,1), (1,1)},  p 在 0 真、在 1 假
```

在 0 上 `◇p` 真（0 看到自己）；但 1 上 `◇p` 假（1 只看到自己，`p` 假），所以 `□◇p` 在 0 假。

在 S5 中，这个反模型不再合法：S5 要求可及关系是等价关系；若 `0R1`，则必须 `1R0`，而 `1` 只看到自己，所以模型不满足对称。更一般地，设 `◇p` 在 `w` 真，取 `wRv` 且 `p` 在 `v` 真。任取 `wRu`；由对称得 `uRw`，再由传递得 `uRv`，所以 `u` 能看到一个满足 `p` 的世界 `v`，即 `◇p` 在 `u` 真。由于 `u` 任意，`□◇p` 在 `w` 真。因此 `◇p → □◇p` 在 S5 中有效。

这个对比说明：**同一个公式在不同框架类上可以有不同命运**，表列法的框架规则决定了搜索空间。S4 的反模型之所以在 S4 合法，是因为它只要求自反和传递，不要求对称；加入 S5 规则后，`0R1` 会强制 `1R0`，原来的赋值不再满足。

## 5.10 终止性与复杂度

- 纯 K 的表列法可能不终止：`F(□φ)` 不断创建新世界。实际实现需要**循环检查（loop checking）**或**阻塞（blocking）**：如果新世界的公式集被祖先世界包含，就停止展开。
- S4/S5 通常用阻塞保证终止。
- 命题 K 的可满足性是 PSPACE-complete；S5 是 NP-complete。表列法的朴素实现可能很慢，优化包括缓存、规则顺序、闭枝优先等。

**阻塞的直觉。** 假设搜索到世界 `w` 时，它的“待满足公式集”已经被祖先世界 `v` 的公式集包含。继续从 `w` 展开，只会重复 `v` 已经做过的结构；如果 `v` 能展开出一个模型，那么把 `w` 映射回 `v` 也能得到模型。于是可以停止这条路径，把它当作“不需要再展开”的开放枝。阻塞不是“随便停”，必须证明被阻塞的世界不会提供新的反例信息；不同的阻塞条件（祖先阻塞、等同阻塞）对应不同的正确性证明。

**常见错误诊断。**

1. **把 `T(□φ)` 当成“创建新世界”**：它只向已经存在的可及世界传播；创建新世界的是 `F(□φ)` 或 `T(◇φ)`。
2. **`F(□φ)` 复用了旧世界**：这会强行把反模型做小，可能把本来开放的分支错误地闭掉。新世界必须是当前枝上未出现过的名字。
3. **β 规则只做一个分支**：`T(φ∨ψ)` 必须同时检查两个分支；只做一个分支不能证明有效。
4. **闭枝条件跨世界使用**：`T p@0` 与 `F p@1` 不构成闭枝；必须是同一世界。
5. **把 S5 说成“所有世界互相可及”**：S5 是等价类内互相可及；不同类之间不可及。
6. **开放枝不检查自洽性**：读出模型后要确认可及关系和赋值确实满足所有节点；仅“没有闭枝”不等于“模型已经构造好”。

**应用与边界。** 表列法适合教学、手算和小规模自动证明；它的输出是一棵树，既能证明有效，也能在失败时给出反模型，这一点比 Hilbert 证明更直观。边界是：朴素表列可能不终止或爆炸；有阻塞也不代表多项式时间；S5 的规则需要小心处理等价类。实际定理证明器通常还会做公式索引、缓存、启发式规则顺序和模型提取。

**迁移检验。** 手写 `□(p∨q) → (□p∨□q)` 的表列，判断它是否有效；如果无效，从开放枝读出反模型。再手写 `◇(p∧q) → (◇p∧◇q)`，比较两者的分支结构。提示：前者在 K 中无效，取 `W={0,1,2}`、`R={(0,1),(0,2)}`、`p` 只在 1 真、`q` 只在 2 真；`□(p∨q)` 在 0 真，但 `□p` 与 `□q` 在 0 都假。后者有效：存在一个同时满足 `p` 和 `q` 的世界，分别给出两个存在见证。

## 5.11 本讲要点

- 表列法 = 反模型构造 + 闭枝检测；所有分支闭 = 有效，开放枝 = 反模型。
- `F(□φ)` 创建新世界；`T(□φ)` 向已有可及世界传播；`T(◇φ)` 也创建新世界。
- β 规则必须穷尽两个分支；α 规则在同一枝上展开。
- 框架规则把 T/4/5/B/D 的系统差异编码进搜索；S5 是等价类内互相可及，不是所有世界互相可及。
- 终止性需要循环检查/阻塞；朴素表列可能不终止或爆炸。
