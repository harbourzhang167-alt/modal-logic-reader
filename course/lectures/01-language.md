# 第一讲 命题逻辑回顾与模态语言

**本讲导入。** 先看两句话：“门是锁着的”和“门必然是锁着的”。命题逻辑只能分别把它们记成 `p` 和 `q`，然后说两者都真或都假；它看不出第二句比第一句多了什么。模态逻辑要补上的，正是“以什么方式为真”：是碰巧真、必然真，还是某个主体知道、某个规范允许。本讲先不急着解释“可能世界”，只做三件事：说明为什么命题逻辑不够、把模态语言写清楚、把自然语言翻译成不含糊的公式。

## 学习目标

学完本讲，你应当能：

- 用一句话说明命题逻辑在什么意义上“不够用”，并举一个模态例子；
- 写出基本模态语言的形成规则，指出 `□`、`◇` 的优先级和辖域；
- 把 3–5 个自然语言句子翻译成模态公式，并写出另一种合理读法；
- 判断一个符号串是否合法，并说明它违反了哪条形成规则；
- 区分真势、认知、道义、时间四种读法，不把 `K_i`、`O`、`G` 混成同一个 `□`。

**先修回顾。** 本讲默认你会：命题联结词的真值表；重言式与代入；分离规则（MP）；集合与二元关系的基本记号。开始前用 2 分钟自测：`p → (q → p)` 为什么是重言式？如果 `R = {(0,1)}`，从 0 出发能到哪些点？如果这两题卡住，先回看命题逻辑的真值表和关系的基本定义；本课程后面会反复用它们。

**本讲在课程中的位置。** 第 1 讲只建立“语言”，不建立“语义”。第 2 讲才会解释 `□` 为什么是真、假；第 3 讲才会问哪些公式可证。因此本讲的翻译练习允许“先写公式、暂不判断真假”，但要求每一步都能说清依据。

## 1.1 从“真”到“必然真”

命题逻辑只关心一个句子在某个赋值下是真还是假。但很多推理关心的不是“真”，而是“以什么方式真”：

- “2 + 2 = 4”不只是真，而且**必然**真。
- “现在正在下雨”可能真，也可能假；它是**偶然**的。
- “如果下雨，地就会湿”与“如果下雨，地就**必然**湿”不是一回事。
- “Alice 知道门是锁着的”与“门是锁着的”也不是一回事：前者多了认知主体。

模态逻辑的做法是：在命题逻辑上增加一元算子 `□`（必然）与 `◇`（可能），然后用**可能世界**或**关系结构**来解释它们。`□A` 读作“必然 A”，`◇A` 读作“可能 A”。

“模态”不限于必然/可能。认知逻辑用 `K_i` 表示“主体 i 知道”，道义逻辑用 `O` 表示“应当”，时间逻辑用 `G`/`F` 表示“将来总是/将来某时”。它们的共同点是：算子的真值不只取决于当前世界的真值，还取决于一组“可及世界”。

**为什么真值表不够？** 真值表把每个原子命题当作孤立的真/假位，公式的真值只由当前赋值决定。但“Alice 知道 P”不只取决于 P 此刻真假：还要看 Alice 认为哪些情况可能；“应当 P”也不只取决于 P 是否发生：还要看规范允许哪些情况。要表达这种“相对于一组替代情况”的真，必须给公式增加一个关系结构；这就是下一讲 Kripke 模型的动机。

**一个常见误解。** `□p` 不是“p 很真”或“p 比 p 更真”，而是“在所有相关替代情况中 p 都真”。同理，`K_a p` 不是“p 是必然的”，而是“在 Alice 不能排除的情况中 p 都真”。把 `□` 当成语气的加强词，后面会接连出错。

## 1.2 命题逻辑的回顾

命题语言由原子命题 `p, q, r, ...` 和联结词组成：

```text
φ ::= p | ¬φ | (φ ∧ φ) | (φ ∨ φ) | (φ → φ) | (φ ↔ φ)
```

给定一个赋值 `v: {p,q,...} → {0,1}`，可以递归计算每个公式的真值。重言式是在所有赋值下都为真的公式，例如：

- `p → p`
- `p ∨ ¬p`
- `(p ∧ q) → p`
- `(p → (q → r)) → ((p → q) → (p → r))`

命题逻辑有两个我们后面要反复使用的性质：

1. **代入**：若 `φ` 是重言式，则把其中的原子命题统一替换成任意公式，得到的仍是重言式。
2. **分离规则（MP）**：从 `φ` 和 `φ → ψ` 可以推出 `ψ`。

**定义拆解。** 上面的语法只规定“哪些符号串是公式”，还没有规定“公式在什么情况下真”。语义部分要另给一个赋值 `v`，把每个原子命题映射到 `{0,1}`，再按联结词递归计算复合公式。语法和语义是两层：`□(p → q)` 是不是合法公式，由形成规则决定；它是不是真，要等第 2 讲给出模型。把这两层混在一起，是初学者最常见的概念错误之一。

**从命题逻辑继承什么。** 我们保留三样东西：联结词的真值行为；重言式的代入实例；MP。模态逻辑新增的不是“更复杂的真值表”，而是一个新的真值依赖维度：公式在某个点上真，可能还要看与这个点相关的其他点。第 2 讲会把“其他点”形式化为可及关系。

## 1.3 基本模态语言

在命题语言上增加 `□` 和 `◇`：

```text
φ ::= p | ¬φ | (φ ∧ φ) | (φ ∨ φ) | (φ → φ) | □φ | ◇φ
```

约定：

- `□` 是原始算子，`◇` 可以由它定义：`◇φ = ¬□¬φ`。
- 反过来也可以：`□φ = ¬◇¬φ`。二者互为对偶。
- 我们只讨论**正常**模态逻辑：包含 K 公理和必然化规则（第三讲）。

**定义拆解。** 把这个定义拆成五件事，逐条问“为什么”：

1. **载体**：原子命题 `p, q, r, ...` 是起点；没有它们，公式无从谈起。
2. **形成规则**：每个联结词/模态词都吃一个或两个已有公式，生成新公式；括号保证唯一可读。`□` 是一元**前缀**算子，只能写在公式左边，不能写成 `p □ q`。
3. **缩写**：`◇φ` 不是新的原始符号，而是 `¬□¬φ` 的缩写。这样只需给 `□` 语义，`◇` 的语义自动得到；反过来也可以选 `◇` 为原始算子。
4. **优先级**：为了少写括号，约定 `¬`、`□`、`◇` 先于 `∧`、`∨`，`∧`、`∨` 先于 `→`、`↔`；但遇到可能歧义时**宁可加括号**。`□p → q` 读作 `(□p) → q`，不是 `□(p → q)`。
5. **系统约定**：“正常”不是所有模态逻辑的默认性质。非正常模态逻辑可能不包含 K 或不对 NEC 封闭；本课程不讨论。我们选正常系统，是为了让第 3 讲的公理系统和第 2 讲的 Kripke 语义能对齐。

**为什么选 `□` 而不是 `◇` 作原始算子？** 纯属约定。两者对偶，选哪个都能定义另一个；选 `□` 只是让“必然”在公理（如 K、T、4）里写起来更整齐。重要的是：**一旦选定，就要在语法、语义、证明里保持一致**，不能一会儿把 `◇` 当原始算子、一会儿又当缩写。

读法：

- `□p`：必然 p。
- `◇p`：可能 p。
- `□□p`：必然必然 p。
- `◇□p`：可能必然 p。
- `□◇p`：必然可能 p。

注意：`◇□p` 与 `□◇p` 一般不等价。前者说“存在一个可及世界，在那里 p 在所有可及世界都真”；后者说“从当前世界看，每个可及世界都能再到一个 p 世界”。它们的量词顺序不同。

## 1.4 辖域：模态逻辑最容易出错的地方

自然语言里的“必然”“可能”是副词，位置很灵活，容易产生辖域歧义。

例 1：

> 如果下雨，那么地必然是湿的。

可以形式化为：

```text
r → □w        （如果下雨，则必然地湿）
□(r → w)      （必然地：如果下雨，则地湿）
```

前者只要求“在当下这场雨里，地湿是必然的”；后者要求“在任何可及世界里，只要下雨，地就湿”。两者强度不同。

例 2（命题版）：

> 可能 p 且 q。

可以读作：

```text
◇(p ∧ q)      （存在一个可及世界，p 和 q 同时真）
◇p ∧ ◇q       （可能 p，且可能 q；不要求同一个世界）
```

前者强于后者：前者要求同一个可及世界同时满足 p、q；后者允许 p 和 q 分别在两个不同的可及世界实现。这是**同一种模态词与联结词的辖域交换**，也是本课程会反复使用的对照。

**一个越界例子。** 自然语言“可能所有人都通过了考试”还会涉及量词：`◇∀x P(x)` 与 `∀x ◇P(x)` 的区别是“同一个世界所有人通过”与“每个人各自可能通过”。这属于**一阶模态逻辑**，本课程的语言只是命题模态逻辑，没有 `∀`；这里只用来说明“先确定辖域”这个一般教训，不要求你写出一阶公式。

例 3（认知版）：

> 如果 Alice 知道 P，那么 P 是真的。

这是认知逻辑的 T 公理：`K_a P → P`。它说的是“知识蕴涵真理”，不是“P 必然真”。不要把 `K_a` 与 `□` 混为一谈。

## 1.5 翻译练习的步骤

拿到一个句子，按下面顺序处理：

1. 找出原子命题，给它们起名字。
2. 找出模态词，确定它管到哪个范围。
3. 判断需要哪种模态：真势、认知、道义、时间？
4. 写出公式，再反向读一遍，检查是否改变了原意。
5. 如果有歧义，写出两个读法，并说明差别。

示例：

> 如果下雨，Alice 就知道地是湿的。

设 `r` = 下雨，`w` = 地湿。两种读法：

```text
r → K_a w        （如果下雨，则 Alice 知道地湿）
K_a (r → w)      （Alice 知道“下雨则地湿”）
```

前者只要求当下知道，后者要求她知道一条规律。选择哪一个，取决于语境。

**完整翻译例题。** 把下面这句话翻译成模态公式，并说明每个符号的依据：

> Alice 知道下雨，但 Bob 不知道地湿；事实上地是湿的。

第一步，列原子命题：`r` = 下雨，`w` = 地湿。第二步，找模态词和主体：`K_a` 读“Alice 知道”，`K_b` 读“Bob 知道”；“不知道”是 `¬K_b`，不是 `K_b¬`。第三步，定辖域：`K_a r` 是“Alice 知道下雨”；`¬K_b w` 是“Bob 不知道地湿”；`w` 是事实“地湿”。第四步，组合：

```text
K_a r ∧ ¬K_b w ∧ w
```

第五步，反读检查：“Alice 知道下雨；Bob 不知道地湿；并且地实际上是湿的。”与原句一致。这里 `¬K_b w` 与 `K_b ¬w` 完全不同：前者是“Bob 不知道 w”，后者是“Bob 知道非 w”；前者不蕴涵后者，反之亦然（在知识逻辑中还需要 T 公理才能从 `K_b ¬w` 推出 `¬w`）。

**常见错误诊断。**

1. **把 `□(p ∨ q)` 写成 `□p ∨ □q`。** 前者是“必然 p 或 q”，后者是“必然 p 或必然 q”。取一个模型：`w` 看到 `v1`（p 真、q 假）和 `v2`（p 假、q 真），则 `□(p∨q)` 在 `w` 真，但 `□p`、`□q` 都假。自检：我写的公式，换一个模型还等价吗？
2. **把“不知道”写成 `K¬`。** “Bob 不知道地湿”是 `¬K_b w`；“Bob 知道地不湿”是 `K_b ¬w`。两者不是一回事。自检：否定号在模态词外，还是里面？
3. **把 `K_a` 当 `□` 用。** `K_a p → p` 是知识逻辑的 T 公理；`□p → p` 是真势逻辑的 T 公理。它们形式相似，但读法、系统、直觉不同。自检：我这里说的是“知道”“相信”“应当”还是“必然”？如果是“相信”，`K_a p → p` 就不该默认成立。

**应用与边界。** 当一句话的真值取决于“在哪些替代情况中成立”时，模态语言有用：知识、时间、规范、程序状态都是例子。反过来，如果只关心当前数据库里的真/假，或者只做命题联结词的真值表，命题逻辑就够了；硬套模态算子只会增加空洞的符号。Kripke 语义也有边界：它不直接表达概率、资源限制、主体间的实际推理过程；这些需要概率逻辑、动态逻辑或认知架构来补。

**迁移检验。** 把“Bob 相信下雨，但 Alice 不知道 Bob 相信下雨”写成公式。一种合理读法是 `B_b r ∧ ¬K_a B_b r`，其中 `B` 读“相信”、`K` 读“知道”。注意外层 `¬K_a` 管的是整个 `B_b r`；如果你写成 `¬K_a r`，说的就是“Alice 不知道下雨”，范围变了。

## 1.6 本讲要点

- 模态逻辑 = 命题逻辑 + 表示“真之方式”的算子。
- `□` 与 `◇` 对偶：`◇φ = ¬□¬φ`；`◇` 是缩写，不是必须的原始符号。
- 模态词的辖域决定公式的含义；`□(p∨q)` 与 `□p∨□q`、`¬K p` 与 `K¬p` 都不同。
- 语法只规定合法符号串，语义要到第 2 讲才给出。
- 不同应用对应不同系统：知识常用 S5，义务常用 D/KD45，时间常用 S4 或线性时间逻辑。
