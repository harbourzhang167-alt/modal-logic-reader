# 模态逻辑六讲：参考答案

> 建模题往往没有唯一答案；下面给出一种合理形式化，并说明理由。  
> 证明题给出的是 Hilbert 风格或语义论证，不一定唯一。

## 第 1 组

**1.1**

- 主联结词：`↔`。
- 原子命题：`p`、`q`。
- Unicode：`□(p → q) ↔ (◇¬p ∨ □q)`。

**1.2**

- (a) `□p ∨ □q`
- (b) `□(p ∨ q)`
- (c) `◇p ∧ ◇q`
- (d) `◇(p ∧ q)`

差别：

- (a) 要求“p 必然”或“q 必然”至少一个成立，强。
- (b) 只要求在每个可及世界至少一个成立；可能 p 在一个世界必然、q 在另一个世界必然，而没有任何一个单独必然。因此 (b) 比 (a) 弱。
- (c) 允许 p 和 q 分别在**不同**的可及世界可能。
- (d) 要求同一个可及世界同时满足 p 和 q，强于 (c)。

**1.3**

- `r → □w`：如果当前世界下雨，那么在当前世界“地湿”是必然的。
- `□(r → w)`：在所有可及世界里，只要下雨，地就湿；它表达的是一条“规律”。

二者一般**不可比**：

- `r → □w` 真而 `□(r → w)` 假：当前世界不下雨，但某个可及世界下雨且地不湿。
- `□(r → w)` 真而 `r → □w` 假：当前世界下雨且地不湿，但所有可及世界都不下雨（于是 `r → w` 空真）。

只有在额外假设（例如当前世界可及自身、且“地湿”的必然性在可及世界间保持）下，才会有更强的联系。

**1.4**

`M, w ⊨ ◇p` 当且仅当存在 `v` 使得 `wRv` 且 `M, v ⊨ p`。  
`M, w ⊨ ¬□¬p` 当且仅当并非“对所有 `v`，若 `wRv` 则 `M, v ⊨ ¬p`”，即存在 `v` 使得 `wRv` 且 `M, v ⊭ ¬p`，即 `M, v ⊨ p`。两者定义相同。

**1.5**

- (a) `K_a P ∧ ¬K_a Q`
- (b) `K_a P ∧ ¬□Q`
- (c) `¬K_a K_b P ∧ ¬K_a ¬K_b P`（Alice 既不知道 Bob 知道 P，也不知道 Bob 不知道 P）

**1.6**

- `□(p → q)`：合法。
- `□p → q`：合法。
- `p □ q`：不合法；`□` 是一元前缀算子，不能放在两个公式中间。
- `◇(p ∧ □q)`：合法。

**本组常见错因。** (1) 把“必然 p 或必然 q”写成 `□(p∨q)`：这是辖域错误，`□` 只作用于紧邻公式。(2) 把 `¬K_a Q` 写成 `K_a ¬Q`：前者是“不知道 Q”，后者是“知道非 Q”；两者在 S5 中可以同时为假。(3) 看到 `p □ q` 觉得“可以理解为 p 必然 q”：语法上不合式，必须先补括号写成 `□(p→q)` 或 `p→□q` 并说明读法。

## 第 2 组

**2.1**

- `◇p`：真（0 看到 1，p 在 1 真）。
- `□p`：真（0 只看到 1，p 在 1 真）。
- `□q`：假（1 上 q 假）。
- `◇q`：假（0 只看到 1，q 在 1 假）。
- `□(p ∨ q)`：真（1 上 p 真）。
- `◇□p`：真（0 看到 1；1 看到 2，p 在 2 真，所以 `□p` 在 1 真）。

**2.2**

```text
W = {0},  R = ∅,  p 在 0 为假
```

`□p` 在 0 空真，`p` 在 0 假，所以 `□p → p` 假。

**2.3**

```text
W = {0, 1},  R = {(0,1)},  p 在 0 真、在 1 假
```

在 0：`p` 真；但 0 看到 1，`p` 在 1 假，所以 `□p` 假。因此 `p → □p` 假。

**2.4**

```text
W = {0},  R = ∅,  p 在 0 为真
```

`□p` 空真，但 `◇p` 假（没有可及世界）。所以 `□p → ◇p` 假。

**2.5**

只在 world 0 失败。0 看到 1，`p` 在 1 真，所以 `□p` 在 0 真；但 `p` 在 0 假，所以蕴涵假。world 1 没有可及世界，`□p` 空真，且 `p` 在 1 真，所以蕴涵真。

**2.6**

```text
W = {0, 1},  R = {(0,1)},  p 只在 1 为真
```

在 0：`□p` 真（所有可及世界都满足 p），`p` 假。这个例子**不**依赖空可及关系；0 有一个可及世界。

**本组常见错因。** (1) 把“`□p` 空真”误读成“`p` 真”：空真只说明没有反例世界，不说明 `p` 在当前世界真。(2) 求 `□p` 时只看一个可及世界：必须检查**所有**可及世界；只要一个不满足就假。(3) 求 `◇p` 时忘了“存在”预设：没有可及世界时 `◇p` 假，而不是空真。(4) 反模型只写 `W` 和 `R` 而漏掉 `V`：没有赋值无法判断原子命题真值。

## 第 3 组

**3.1**

```text
1. p → p                       taut
2. □(p → p)                    NEC 1
```

**3.2**

```text
1. p → (q → p)                 taut
2. □(p → (q → p))              NEC 1
3. □(p → (q → p)) → (□p → □(q → p))   K
4. □p → □(q → p)               MP 2,3
```

**3.3**

```text
1. (p ∧ q) → p                 taut
2. □((p ∧ q) → p)              NEC 1
3. □((p ∧ q) → p) → (□(p ∧ q) → □p)   K
4. □(p ∧ q) → □p               MP 2,3
```

**3.4**

反模型：`W = {0}, R = ∅, p 在 0 为假`。`□p` 空真，`p` 假，所以 `□p → p` 假。由可靠性，它不可在 K 中证明。

**3.5**

- (a) 最小系统 T
- (b) 最小系统 S4
- (c) 最小系统 S5

**3.6**

约定 `◇p = ¬□¬p`。

```text
1. □¬p → ¬p                    T（A 取 ¬p）
2. (□¬p → ¬p) → (p → ¬□¬p)     taut
3. p → ¬□¬p                    MP 1,2
```

**3.7**

先用 3.3 得 `□(p∧q) → □p` 和 `□(p∧q) → □q`。再由重言式

```text
(□(p∧q) → □p) → ((□(p∧q) → □q) → (□(p∧q) → (□p ∧ □q)))
```

两次 MP 即得。完整 11 行版本见 `code/solutions/lab05_proofs.py`。

**本组常见错因。** (1) 对假设使用 NEC：NEC 只能对已证定理使用；若把 `p` 当假设，`□p` 不是合法步骤。(2) 把 K 写成 `□(p→q) → (□p→q)`：后件应是 `□q`，分配的是必然算子，不是去掉必然。(3) 只列重言式就宣布完成：必须用 MP 把 K 实例和重言式接起来，每一步都要有依据。(4) 用“显然”跳过重言式验证：命题重言式也要写清楚或注明可验证。

## 第 4 组

**4.1**

设 `F` 自反。取任意模型和世界 `w`。若 `M, w ⊨ □p`，因为 `wRw`，所以 `M, w ⊨ p`。因此 `□p → p` 在 `w` 真。

**4.2**

```text
W = {0},  R = ∅,  p 在 0 为假
```

`□p` 空真，`p` 假。

**4.3**

设 `F` 传递。若 `M, w ⊨ □p`，取任意 `wRv` 和任意 `vRu`。由传递性 `wRu`，所以 `M, u ⊨ p`。因此 `□p` 在 `v` 真；由于 `v` 任意，`□□p` 在 `w` 真。

**4.4**

```text
W = {0, 1},  R = {(0,1), (1,0)},  p 只在 1 为真
```

这个关系不自反，也**不传递**：有 `0→1` 与 `1→0`，却缺少 `0→0`（同样缺少 `1→1`）。在 0：`□p` 真（1 上 p 真）；在 1：`□p` 假（1 看到 0，p 在 0 假）。所以 `□□p` 在 0 假。

**4.5**

设 `F` 欧几里得。若 `M, w ⊨ ◇p`，取 `wRv` 且 `M, v ⊨ p`。对任意 `wRu`，由欧几里得得 `vRu`，所以 `M, u ⊨ ◇p`。因此 `M, w ⊨ □◇p`。

反模型：

```text
W = {0, 1},  R = {(0,1)},  p 只在 1 为真
```

`◇p` 在 0 真；1 没有可及世界，所以 `◇p` 在 1 假，`□◇p` 在 0 假。这个关系不欧几里得（0→1 要求 1→1，缺失）。

**4.6**

自反意味着每个 `w` 都有 `wRw`，所以每个世界至少有一个可及世界（它自己），即串行。因此自反框架类是串行框架类的子类；T 的框架类比 D 窄，T 的定理集比 D 大。

**4.7**

无效。反模型：

```text
W = {0, 1, 2}
R = {(0,1), (1,0), (1,2), (2,1)}
p 在 1、2 为真，在 0 为假
```

关系对称。在 0：`□p` 真（只看到 1，p 真）；在 1：`□p` 假（看到 0 和 2，p 在 0 假）。所以 `□□p` 在 0 假。

**4.8**

把极大一致集当作世界，定义典范关系 `wRv` 当且仅当 `{A | □A ∈ w} ⊆ v`，用赋值 `p ∈ V(w)` 当且仅当 `p ∈ w`。对公式结构归纳证明真值引理：`A ∈ w` 当且仅当典范模型在 `w` 满足 `A`。若 `A` 不可证，则 `{¬A}` 一致，扩展成极大一致集 `w`，由真值引理得到 `¬A` 可满足，故 `A` 不普遍有效；逆否即完全性。

**4.9**

框架有效要求对**所有赋值** `V` 都为真。赋值是 `W` 的子集，量化 `V` 相当于量化 `W` 的幂集，因此是二阶量化。只有当公式属于 Sahlqvist 等特殊类时，才等价于一阶条件。

**本组常见错因。** (1) 反方向证明不检查赋值合法性：例如 T 的证明里若 `p` 在见证世界 `w` 也为真，`□p` 的计算会自相矛盾；必须先利用“非自反”保证 `w` 不是自己的可及世界。(2) 把“模型有效”当“框架有效”：固定一个 `V` 为真不够，框架有效要对所有 `V`。(3) 把“不自反”直接当成“不传递”：两者独立；反例要给出缺失的具体传递边。(4) 把 5 的欧几里得条件写成对称：`wRv∧wRu⇒vRu` 与 `wRv⇒vRw` 不同；B 才是对称。

## 第 5 组

**5.1**

```text
T □(p → q) @ 0
F (□p → □q) @ 0
├─ T □p @ 0
├─ F □q @ 0
├─ 0R1, F q @ 1          （F□）
├─ T p @ 1               （T□p）
├─ T (p → q) @ 1         （T□(p→q)）
├─ F p @ 1               （T→ 分支 1）
│  └─ 闭：T p 与 F p
└─ T q @ 1               （T→ 分支 2）
   └─ 闭：T q 与 F q
```

两枝都闭，公式有效。

**5.2**

```text
T □p @ 0
F p @ 0
```

0 没有可及世界，`T□p` 不传播；开放。反模型：`W={0}, R=∅, p` 在 0 假。`□p` 空真，`p` 假。

**5.3**

```text
T p @ 0
F □p @ 0
0R1, F p @ 1
```

开放。反模型：`W={0,1}, R={(0,1)}, p` 在 0 真、在 1 假。

**5.4**

在 S4 中：

```text
T ◇p @ 0
F □◇p @ 0
0R1, T p @ 1            （T◇）
0R2, F ◇p @ 2           （F□）
T □¬p @ 2               （F◇ 转成 T□¬p）
2R2, F p @ 2            （自反）
```

开放。反模型可以取：

```text
W = {0,1,2}
R = {(0,0),(0,1),(0,2),(1,1),(2,2)}
p 在 1 真，在 0、2 假
```

在 0：`◇p` 真（看到 1）；2 上 `◇p` 假（只看到自己，p 假），所以 `□◇p` 在 0 假。

**5.5**

`F(□φ)` 表示“存在一个可及世界，在那里 φ 为假”。这个见证世界可能必须与所有已有世界都不同；如果复用旧世界，就可能把额外的公式强加给它，导致错误的闭枝或漏掉反模型。新世界保证我们只施加规则要求的约束。

**5.6**

因为 `□φ` 在没有任何可及世界时**空真**；没有世界需要检查，所以不需要添加任何公式。若强行创建一个世界，就会错误地要求 `φ` 在那个世界为真，从而把本应开放的分支闭掉。

**5.7**

`F(□φ)` 每次都创建新世界，K 中可能无限展开。阻塞的做法是：当新世界的公式集（或其在子公式集上的标记）被某个祖先世界包含时，停止展开该枝；这对应“反模型可以有限化”的直觉。S4/S5 中阻塞更简单，因为关系有自反/传递/对称性。

**本组常见错因。** (1) `F(□φ)` 复用了旧世界：会把额外约束强加给旧世界，可能错误闭枝；见证世界必须是当前枝上的新名字。(2) β 规则只做一个分支：`T(φ∨ψ)` 必须两枝都检查，只有全部闭才证明有效。(3) 跨世界闭枝：`T p@0` 与 `F p@1` 不矛盾；闭枝要求同一世界。(4) 把 S5 说成“所有世界互相可及”：S5 是等价类内互相可及，类间不可及。(5) 开放枝不检查自洽性：读出的 `W/R/V` 要逐节点验证，不能只看“没有闭枝”。

## 第 6 组

**6.1**

- `K_a p`：假（a 认为 1 可能，p 在 1 假）。
- `K_a ¬p`：假（a 认为 0 可能，p 在 0 真）。
- `¬K_a p ∧ ¬K_a ¬p`：真。
- `K_a (p ∨ ¬p)`：真（排中律在所有可及世界成立）。

**6.2**

- (a) `K_a K_b P`
- (b) `¬K_b K_a P`
- (c) `K_a P ∧ ¬K_b P`

**6.3**

只剩 world 0。`K_a p` 在 0 上真，因为限制后的模型中 a 的可及世界只有 0，而 p 在 0 真。

**6.4**

- (a) `p U q`
- (b) `F q`
- (c) `G ¬q`

**6.5**

- (a) `O p ∧ F q`（这里的 `F` 是“禁止”，不是“将来”）
- (b) `O p → P p`，即 D 公理。

**6.6**

- 知识：S5。知识蕴涵真理，且主体能反思自己的知识/无知。
- 信念：KD45。信念需要一致（D），但不要求真实（拒绝 T）。
- 义务：D 或 KD45。义务不蕴涵实际，拒绝 T；D 排除“应当却不容许”的空义务，但不自动消解所有义务冲突。
- 包含现在的将来：S4。`G` 自反且传递；若只关心严格将来，可用 K4 或更弱的传递系统。

**6.7**

公开公告把模型限制到与公告内容一致的世界，从而删除不可能的情况；每轮“我不知道”的公告进一步删除世界。对 `k` 个泥孩子，前 `k-1` 轮“无人知道”逐层排除“只有更少泥孩子”的可能，第 `k` 轮每个泥孩子都能排除“自己干净”的世界，于是确定自己的状态；反复的公开公告也让这一推理成为公共知识。

**本组常见错因。** (1) 把 `K_i A` 写成 `A`：知道不等于事实；在 KD45 中甚至可以知道假命题。(2) 把“公开宣布 p”与“p 为真”混同：公告还要求公共知识/模型限制，且假公告在 PAL 中空真而不是“让人知道假”。(3) 用 S5 建模信念：S5 强制 `K_i A→A`，信念应允许错误，常用 KD45。(4) 给道义逻辑加 T：`O A→A` 会把义务变成事实；D 才是“义务⇒允许”。(5) 时间逻辑忘了声明严格/非严格：`Gφ→φ` 只在包含当前时刻时成立。
